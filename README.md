# ux-analyze-by-hani

A Claude skill for running a first-pass **heuristic evaluation / UX audit** of a live website in the browser.

It covers Nielsen's 10 usability heuristics, accessibility, and visual hierarchy. Scope and the user's job to be done (JTBD) are set up front, every issue gets a severity and weighted priority, and the result is a clear report for designers, PMs and founders.

## Contents

`ux-analyze-by-hani/SKILL.md` holds the skill's instructions and workflow.

## Usage

Add the `ux-analyze-by-hani` folder to your Claude skills, open the site you want to review in Chrome (with Claude in Chrome), and ask Claude to audit the page.
